# Bode Grapher: Interactive LTSpice RAW Viewer

Welcome to **Bode Grapher**, a lightweight, web-based tool designed to help you analyze circuit frequency responses directly from LTSpice's `.raw` files. 

No software installation, Python scripts, or complicated setups are required. It runs entirely inside your internet browser!

## How It Works

When you run an **AC Analysis** in LTSpice, the simulator saves the resulting data (frequencies, voltages, currents) into a binary file with a `.raw` extension. 

Bode Grapher takes that binary file and does the following:
1. **Local Parsing**: When you drag and drop your `.raw` file into the app, it uses JavaScript's `FileReader` and `DataView` APIs to read the raw binary headers and extract the floating-point values locally. *Your data never leaves your computer; it is not uploaded to any server!*
2. **Data Conversion**: The app reads the complex numbers generated by LTSpice, calculates the signal magnitude, converts it instantly into Decibels ($dB$), and matches it to its frequency array.
3. **Automated Analytics**: The tool automatically calculates the Maximum Gain, searches for $-3dB$ crossing points (automatically detecting if your circuit is a Low-Pass, High-Pass, or Band-Pass filter), and computes the **Stopband Slope** in dB/decade.

## Features

- **Interactive Graphing**: Hover over any point to instantly see exact Frequency and Gain values. Switch smoothly between any nodes defined in your circuit.
- **Dual Cursors**: A built-in dual-cursor menu allows you to place two independent markers on the plot. Input a target Frequency or target Gain, and the app mathematically interpolates the exact crossing matching your criteria, then calculates $\Delta f$, $\Delta dB$, and the slope between the points.
- **Freq/Gain Finder**: A secondary quick-lookup tool for instant, single-point value testing.

## Technology Stack

This tool proves that powerful engineering dashboards can be built using purely native web standards!

- **HTML5 & CSS3**: Used for the layout and the modern, high-contrast "glassmorphism" dark-mode styling.
- **Vanilla JavaScript (ES6)**: Handles all the heavy lifting, including binary file parsing (`DataView`), logarithmic mathematics, UI state mapping, and linear interpolation algorithms, without needing external framework bloat like React or Vue.
- **Plotly.js**: An open-source graphing library built on top of `d3.js` and `WebGL`. We use Plotly to render the responsive, highly optimized logarithmic charts with custom axis scaling and interactive hover capabilities. Plotly is the *only* external dependency used by this app.

## Quick Start

1. Run an `.ac` simulation in LTSpice.
2. Locate the generated `.raw` file in your circuit's folder.
3. Open `viewer.html` in Chrome, Firefox, Safari, or Edge.
4. Drag and drop your `.raw` file onto the webpage.
5. Have fun analyzing your circuit!
